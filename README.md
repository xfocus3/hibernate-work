# Hibernate private working repository

Sandcastle configuration and workflow entry points live on this control branch. The clean `upstream-main` branch tracks the official Hibernate contribution baseline. Each new issue starts from a freshly verified upstream SHA; existing issue branches are preserved.

Implementation, review, test evidence, and progress discussions stay private here. Public publication contains only the reviewed source patch, regression tests, and sanitized PR description. Public PR feedback is linked back to its private issue.

Tool implementation: https://github.com/xfocus3/sandcastle
Upstream: https://github.com/hibernate/hibernate-orm
Publication fork: https://github.com/xfocus3/hibernate-orm

Integration status: setup in progress; publication and feedback automation are not active yet.
